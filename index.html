What It Does

You write FAQs in a JSON file. The bot matches customer questions to your answers using text similarity. If it can't find a match, it says "I don't know." No AI generation, no internet required, no API keys.

  1. Write your FAQs (question + answer pairs) in a JSON file
  2. pip install flask && python server.py
  3. Open http://localhost:5000 in any browser
  4. Customers ask questions → bot shows your pre-written answers

Limitations (Important)

What This Is NOT

  • Not generative AI — does not create new answers. Only matches from your FAQs.
  • No multi-turn conversations — each question is matched independently.
  • No email/SMS notifications — no external integrations.
  • No analytics dashboard — no usage tracking or reporting.
  • No admin panel — edit JSON files directly to update FAQs.
  • Single language (English) — other languages require manual translation.
